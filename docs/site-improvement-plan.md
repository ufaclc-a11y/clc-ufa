# План улучшения сайта: совет → исполнение

Ограничения: сохранить маршруты, набор и порядок секций, фотографии и содержание. Форму заявки не менять. Не добавлять новые функции или рекламные обещания.

## Совет дизайнера

1. Сделать первый экран компактнее: заголовок 34/56/72 px по брейкпоинтам, межстрочный интервал 1.08, описание с более высоким контрастом. Сохранить контакты и показатели.
2. Повысить читаемость мелких ссылок и рубрик на светлом фоне: тёмный оттенок оранжевого #A84300; фирменный #FF6B00 оставить для акцентов на тёмном фоне.
3. Увеличить подписи изделий и описания услуг. Сохранить сетки, число карточек и реальные фотографии.
4. Показывать названия работ портфолио постоянно, включая сенсорные устройства. Добавить отклик при клавиатурном фокусе и нажатии.
5. Исправить шапку на планшетах: компактное меню до 1280 px, прокрутка длинного меню, исключение скрытых ссылок из Tab, закрытие по Escape и обозначение текущего раздела.

## Заключение Скептика

План одобрен. Общие компоненты необходимо проверить и на внутренних страницах. Не усиливать уже плотное затемнение карточек услуг. На 1280 px проверить, что логотип, навигация и контакты помещаются. Не публиковать накопленные изменения рабочего дерева: переносить только новые правки в чистый checkout актуальной main.

## Проверка и публикация

- Сравнить скриншоты localhost в двух проходах через Puppeteer.
- Проверить ширины 375, 768, 1024, 1280 и 1440 px, отсутствие горизонтального переполнения, меню и портфолио.
- Проверить ESLint для изменённых компонентов.
- Публиковать отдельным коммитом в main; GitHub Actions выполняет lint, тесты, сборку и проверку типов перед развёртыванием.

Состояние публикации и результаты фактических проверок сообщаются в ответе после выполнения.
