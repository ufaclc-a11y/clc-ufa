## Порядок изменений

1. Добавлены постоянные редиректы www → https://clc-ufa.ru и HTTP за прокси → HTTPS, а также старого адреса /services/gravirovka-nemetalah на актуальную страницу. HTTP главной уже возвращал 301 на HTTPS при внешней проверке. HTTPS-проверка с этой машины ограничена ошибкой Schannel; состояние опубликованных www/alias нужно проверить после выкладки.
2. Убрано повторное добавление бренда в title услуг, посадочных и товаров; og:url соответствует странице. При переносе на актуальный main сохранены уже исправленные Promise params, таблицы цен и Product.offers.
3. Email-заявка считается подтверждённой только после принятия письма SMTP-сервером. Отсутствие SMTP возвращает 503, honeypot не создаёт подтверждённую заявку. Открытие мессенджера — отдельная микроконверсия.
4. Для резки, гравировки, фанеры, МДФ, трафаретов и UV DTF уточнены поисковые описания и требования к расчёту. Использованы существующие тарифы и фотографии. Добавлены переходы к форме, инструкции по макетам и подбору шрифта.
5. Уточнены title/description подборщика шрифтов и статьи об адреснике; статья связана со страницей заказа адресников.
6. В форме контакт проверяется до отправки, клиентская проверка файлов совпадает с серверной: до 5 файлов, 20 МБ каждый, 40 МБ суммарно. Улучшены мобильные отступы, размер ввода и переход к форме под фиксированной шапкой. В письме указывается страница заявки.

## Цели Метрики — требуется настройка в кабинете

Счётчик: 53776969. Код отправляет события, но не создаёт цели в личном кабинете.

| JavaScript-событие | Значение |
| --- | --- |
| order_email | Подтверждённое принятие письма SMTP-сервером; не подтверждает прочтение или продажу |
| order_messenger_open | Попытка открыть мессенджер с текстом; параметр channel. Не заявка |
| contact_phone / contact_email / contact_whatsapp / contact_telegram / contact_max | Клик по контакту мастерской. Не подтверждённое обращение |
| order_form_start | Первое изменение формы за её текущий сеанс |
| order_submit_attempt | Попытка отправки после клиентской проверки |
| order_submit_error | Ошибка отправки; технический тип и HTTP-статус |

Старые order_whatsapp/order_telegram/order_max больше не используются формой.
Не объединять их историю с подтверждёнными заявками. В параметры аналитики не отправляются контакты, текст заявки или имена файлов.
Первый просмотр учитывается при init Метрики; переходы Next.js учитываются отдельно. Существующая политика загрузки счётчика не менялась.

## После публикации

- Проверить HTTP/HTTPS, www, alias, canonical и доступность восьми приоритетных страниц на публичном сайте.
- В Search Console проверить индексирование и выбранный Google canonical. Доступа к этим данным в CSV нет. Отправить изменённые приоритетные URL на проверку индексирования; sitemap уже содержит их.
- В Метрике создать перечисленные JavaScript-цели и разделить заявки и контактные клики. Проверить канал «Поисковые системы → Google».
- Проверить доставку одной контрольной заявки с владельцем почтового ящика. Автоматическая проверка использует подменённые ответы API, реальные письма не отправляет.
- Записать фактическую дату публикации. Через 28 дней сравнить страницы и запросы с предшествующими 28 днями; через 8–12 недель оценить устойчивость результата.
- Учитывать показы, клики, CTR, позиции одинаковых запросов, подтверждённые email-заявки и фактические обращения. Не оценивать продажи по кликам мессенджера и не обещать рост по одной средней позиции.

Изменения проверены в отдельной рабочей копии актуального main; опубликованные прайсы и политика согласия на аналитику сохранены. Итог публикации следует сверять с GitHub Actions. Настройки кабинетов и последующая оценка трафика остаются отдельными действиями.
