## Чеклист для каждой страницы

Перед работой над страницей — прочитай её файл и сделай скриншот. Затем проверь каждый пункт:

### 🖼 Визуал
- [ ] **Hero-фото** — есть реальная фотография (не заглушка), занимает значимую часть экрана
- [ ] **Фото в секциях** — карточки, блоки, списки содержат фото из `public/images/`
- [ ] **Нет пустых серых прямоугольников** — все `<Image>` ссылаются на существующие файлы
- [ ] **Фото подобраны по смыслу** — резка → фото резки, гравировка → фото гравировки

### ✍️ Текст
- [ ] **Заголовок H1** — конкретный, содержит ключевое слово, не «Добро пожаловать»
- [ ] **Подзаголовок/лид** — 1–2 предложения, объясняет суть страницы
- [ ] **Основной текст** — реальный контент, не «Lorem ipsum», не заглушки вроде «Текст раздела»
- [ ] **Нет пустых секций** — каждая секция (`<section>`) содержит содержательный текст
- [ ] **Нет placeholder-текста** — нет «[вставить текст]», «TODO», «Описание»

### 📞 CTA (призывы к действию)
- [ ] **Есть минимум 1 CTA** — кнопка WhatsApp, Telegram, форма или «Написать»
- [ ] **CTA понятен** — не «Узнать больше», а «Написать в WhatsApp», «Заказать», «Позвонить»
- [ ] **CTA ведёт куда нужно** — ссылки рабочие, мессенджеры открываются с предзаполненным текстом

### 🔍 SEO
- [ ] **Ключевые слова проверены в Яндекс Вордстате** — перед написанием title, description и текста страницы открой [wordstat.yandex.ru](https://wordstat.yandex.ru), введи тематику страницы + «Уфа», выбери реальные фразы с ненулевой частотностью. Не придумывай формулировки из головы — используй то, что люди реально ищут.
- [ ] **`title`** — уникальный, содержит главную ключевую фразу из Вордстата + «Уфа», до 60 символов
- [ ] **`description`** — 140–160 символов, содержит 2–3 ключевые фразы из Вордстата естественным образом
- [ ] **H1 совпадает с тематикой title** — не дублирует дословно, но содержит ту же ключевую фразу
- [ ] **Текст страницы** — ключевые фразы из Вордстата встречаются в тексте органично, без спама
- [ ] **`canonical`** — указан правильный URL
- [ ] **JSON-LD** — есть структурированные данные (LocalBusiness, Product, Article или BreadcrumbList)
- [ ] **Хлебные крошки** — компонент `<Breadcrumbs>` подключён

> **Как работать с Вордстатом:**
> 1. Открой wordstat.yandex.ru → выбери регион «Уфа»
> 2. Введи базовый запрос: «лазерная резка», «гравировка на металле», «медали на заказ» и т.д.
> 3. Смотри на левую колонку — это что ищут люди. Правая — похожие запросы, там часто есть неочевидные формулировки
> 4. Выбирай фразы с частотностью от 50/мес и выше — это реальный спрос
> 5. Фразы с «цена», «стоимость», «заказать», «купить» — коммерческие, их особенно важно включать в title и description

### 📐 Дизайн
- [ ] **Страница не пустая** — при скролле нет белых «дыр»
- [ ] **Цвета соответствуют бренду** — `#FF6B00` (оранжевый), `#1A1A1A` (тёмный), `#F5F4F0` (тёплый белый)
- [ ] **Мобильная версия** — секции не разваливаются на 375px
- [ ] **Нет текста поверх фото без контраста** — тёмный оверлей или белый текст

### 🗂 Данные
- [ ] **Данные из `data/`** — страница использует реальные данные, не захардкоженные заглушки
- [ ] **Фото существуют** — все пути `public/images/...` указывают на реальные файлы

## Алгоритм работы над страницей

1. **Скриншот** — сделай через Puppeteer, посмотри что есть сейчас
2. **Читай файл** — `Read app/[страница]/page.tsx`
3. **Прогони чеклист** — отметь что выполнено, что нет
4. **Подбери фото** — из списка выше выбери подходящие по смыслу
5. **Напиши текст** — реальный, про конкретную услугу/изделие в Уфе
6. **Внеси правки** — Edit/Write
7. **Скриншот после** — сравни до/после
8. **Обнови трекер** — исправь статус в таблице выше

## Типовые ошибки

| Ошибка | Как исправить |
|---|---|
| Пустая hero-секция (тёмный фон без фото) | Добавь `<Image>` с `opacity-30..50` и двойной градиент поверх |
| Карточки без фото | Добавь `relative aspect-[4/3]` + `<Image fill className="object-cover">` |
| Кнопка «Узнать больше» без цели | Замени на WhatsApp/Telegram с `?text=...` |
| Секция «Почему мы» только с текстом | Добавь иконки через `<SymbolIcon>` из `components/Icons.tsx` |
| Страница обрывается без CTA | Подключи `<CTASection dark />` в конце |

## Hero-фото страниц категорий портфолио

Файл категорий: `app/portfolio/[category]/page.tsx`  
Маршрут: `/portfolio/[category]` — 22 страницы (по одной на каждую категорию)

### Методология подбора фото

1. **Получи список файлов категории** через `Get-ChildItem public/images/portfolio/${id}-*.jpg`
2. **Проверь размеры** через PowerShell + `System.Drawing`:
   ```powershell
   Add-Type -AssemblyName System.Drawing
   $img = [System.Drawing.Image]::FromFile("$pwd\public\images\portfolio\${id}-001.jpg")
   "$($img.Width)x$($img.Height)"
   $img.Dispose()
   ```
3. **Критерий выбора:** ширина ≥ 800px **И** горизонтальная ориентация (ширина > высота)
4. **Если нет горизонтальных** — берём лучшее вертикальное, `object-cover` заполнит кадр
5. **Предпочитай:** более высокое разрешение, выразительный сюжет, хорошее освещение
